## Project Overview
During this internship, I worked on analyzing retail transaction data to extract valuable insights. My primary focus was on data cleaning, merging datasets, performing statistical and visual analysis, and implementing SQL queries for data extraction and transformation.

## Tasks Performed
- **Data Importing:** Utilized the Pandas library to import data from `Retail_data_transaction.csv`.
- **Data Merging:** Combined Transaction and Response tables to derive deeper insights.
- **Outlier Detection:** Applied Box Plot analysis to identify and handle outliers.
- **Statistical Analysis:** Conducted a detailed statistical study of the dataset.
- **Churn Analysis:** Analyzed customer churn behavior and patterns.
- **Data Visualization:** Created Scatter Plots to examine data distribution trends.
- **SQL Querying:** Executed various SQL queries to filter, aggregate, and extract meaningful insights from structured data.
- **Presentation:** Compiled findings into a well-structured PowerPoint presentation.
